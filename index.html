Capabilities

Engineered for professionals.

Native editable equations

Pages and Keynote receive true native structures, Word receives OMML, LibreOffice receives StarMath. Any content outside the convertible set is preserved as source text — nothing is ever discarded.

Native tables

Markdown and HTML tables are reconstructed as genuine tables with editable cells, including embedded equations.

Single-pass multi-target

One clipboard conversion serves Apple, Microsoft and LibreOffice targets simultaneously, with automatic plain-text delivery to markdown editors.

State-of-the-art OCR

KlipOCR integrates a highly optimized OvisOCR2 build with top-1 accuracy, reading-order Markdown output and structured HTML tables.

Air-gapped by design

Both applications operate without network access. Models, conversion and rendering execute locally at all times.

Questions

Frequently asked.

Which systems are supported?

Klip requires macOS 13 or later; KlipOCR requires macOS 14 or later. Both require Apple Silicon.

Does any data leave the machine?

No. Both applications are 100% air-gapped. Recognition, conversion and rendering execute locally with no network dependency.

How accurate is the recognition?

KlipOCR uses a highly optimized OvisOCR2 engine with state-of-the-art performance and top-1 accuracy on standard benchmarks.

What happens to unsupported equations?

Content is always preserved. Anything outside the convertible set is retained as source text.

How are markdown editors handled?

Markdown targets such as Obsidian, Typora and Bear automatically receive clean plain text at paste time.

When are downloads available?

Download buttons are placeholders until the first signed releases ship, at which point they will reference the release files directly.
