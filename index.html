05 — faq

Asked often.

Which macOS versions?

Klip needs macOS 13+, KlipOCR needs macOS 14+ (ScreenCapture). Apple Silicon only.

Does anything leave my Mac?

No. OCR models run bundled on-device; Klip converts locally. No accounts, no cloud.

What if an equation can't convert?

It never vanishes — Klip falls back to the $source$ text so nothing is lost.

How do Obsidian / Typora / Bear get plain text?

The app detects markdown targets at paste time and filters to plain text automatically.

Where do downloads live?

Download buttons above are placeholders until the first signed DMGs ship — then they point at the release files.
